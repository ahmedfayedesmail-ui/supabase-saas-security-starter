# Supabase SaaS Security Starter

Validation-stage assets for a Supabase multi-tenant SaaS starter with security verification positioning.

## Scope
- Landing A (Speed)
- Landing B (Security)
- Lemon Squeezy webhook handler template
- Plausible event tracking
- Automated local tests for attribution/webhook logic

## Validation status
End-to-end third-party integration remains blocked until a real domain, Lemon Squeezy Test Mode, webhook endpoint, and Plausible site are connected.
