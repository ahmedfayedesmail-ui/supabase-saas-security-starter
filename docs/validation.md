# Validation Protocol

The integration gate is intentionally blocked until real evidence exists.

Required evidence:
1. Browser client event with variant A
2. Browser client event with variant B
3. UTM attribution
4. Lemon Squeezy Test Mode transaction
5. Webhook receives custom_data.variant
6. checkout_paid appears in Plausible
7. Variant A cross-verification
8. Repeat for Variant B

Do not fabricate timestamps, screenshots, PASS/FAIL states, or third-party dashboard evidence.
